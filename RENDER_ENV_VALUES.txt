================================================================================
DEPLOYMENT STEPS
================================================================================

1. BACKEND DEPLOYMENT:
   - Go to Render Dashboard
   - Create new Web Service
   - Connect GitHub repo: ramos04043/artfully-lms
   - Root Directory: backend
   - Build Command: pip install -r requirements.txt
   - Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
   - Copy ALL backend variables above into Environment tab
   - Click "Create Web Service"
   - Wait for deployment (3-5 minutes)
   - Note the URL (e.g., https://artfully-lms-api.onrender.com)

2. FRONTEND DEPLOYMENT:
   - Create new Static Site
   - Connect same GitHub repo
   - Root Directory: frontend
   - Build Command: npm install && npm run build
   - Publish Directory: dist
   - Copy ALL frontend variables above into Environment tab
   - IMPORTANT: Update VITE_API_URL with actual backend URL from step 1
   - Click "Create Static Site"
   - Wait for deployment (2-3 minutes)

3. POST-DEPLOYMENT:
   - Update backend CORS_ORIGINS with actual frontend URL
   - Redeploy backend
   - Test: Visit frontend URL
   - Test: Visit backend-url/health
   - Test: Visit backend-url/docs

4. UPDATE CORS (IMPORTANT!):
   After both services deploy, update backend CORS_ORIGINS:
   
   CORS_ORIGINS=["https://your-actual-frontend-url.onrender.com","http://localhost:5173"]
   
   Note: Use JSON array format as shown. The backend parser now handles both JSON arrays and comma-separated strings.
   
   Then click "Manual Deploy" → "Deploy latest commit" in backend service

================================================================================
TROUBLESHOOTING
================================================================================

If backend fails to start:
- Check logs in Render dashboard
- Verify all environment variables are set
- Test ZendBX connection: curl https://api.zendbx.in

If frontend can't connect to backend:
- Verify VITE_API_URL is correct
- Check CORS_ORIGINS includes frontend URL
- Test backend health: visit /health endpoint

If emails not sending:
- Verify Gmail app password is correct (16 chars with spaces)
- Check SMTP settings
- View logs for SMTP errors
